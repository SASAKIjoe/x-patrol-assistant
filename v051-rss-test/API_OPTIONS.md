# 新着判定

登録済みの公開XアカウントをKeepの無料RSSで順次照合します。[提供元の説明](https://keep.md/tools/twitter-rss-feed)では、無料配信は24時間ごと・最新20件です。[公開ツールの取得制限](https://keep.md/docs/api)に配慮し、アプリ側は約1.25秒以上の間隔で取得します。制限や取得失敗は未判定のまま、次回再試行します。

本人投稿と認めるのはRSSの `dc:creator` とX投稿URLのアカウント名が登録候補と一致する項目だけです。初回は基準、次の投稿IDを確認した場合のみ●です。X公式API、当アプリによるXスクレイピング、自動いいね、閉じたPWAでの常時巡回はありません。
