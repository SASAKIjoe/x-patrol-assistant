対象は登録済みの `@tony_sunflower`、`@iyokanlove`、`@dusmel_clean`。未登録なら「?」内の「試験3人を登録」で追加できます。更新を押すとKeepの無料RSSを読み、投稿URLとRSSの投稿者が両方一致する本人投稿だけを比較します。初回は基準作りなので●を出しません。次回以降、より新しい投稿IDを受け取った人を●で表示し、絞り込みで「● 新着」を選べます。

✔は人間がXの投稿を確認した記録です。いいねの記録ではありません。確認で●を消し、取り消すと直前の未読状態に戻します。RSS取得失敗・対象外・投稿なしは新着未判定として扱い、勝手に「新着なし」と断定しません。

無料RSSは提供元の説明では約24時間ごとに更新され、直近20件です。返信は含まれず、リポストは混在します。高頻度投稿や配信停止は見逃し得ます。X公式APIではなく外部RSSです。利用条件や配信仕様が変わる可能性があります。

この試験版は旧 `v051-ui-test/` と別のPWA ID、パス、IndexedDB、サービスワーカーキャッシュを使用します。初回は旧UI試験版の保存データを読み取り専用で複製し、以降は同期しません。旧版の保存データは変更しません。JSONの保存・復元にはRSS確認記録も含まれます。初回利用前にも旧版でJSONを保存してください。

Android実機での動作は未検証です。詳しい結果はRESULT.md、確認手順はAndroid.mdをご覧ください。
