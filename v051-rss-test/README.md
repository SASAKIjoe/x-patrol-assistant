# SNS WATCH BOX｜無料RSS・3人試験

WORK_CODE: SNS-WATCH-PWA-054-RSS  
TASK_ID: SNS_WATCH_BOX_PWA_RSS_PILOT_V01

公開試験URL: https://sasakijoe.github.io/x-patrol-assistant/v051-rss-test/  
GitHub Pagesでの表示と試験対象3人のRSS更新を確認しました。Android実機の確認はこれからです。

対象は `@tony_sunflower`、`@iyokanlove`、`@dusmel_clean` の3人。候補に登録するとKeepの無料RSSを自動で読み、投稿URLとRSSの投稿者が両方一致する本人投稿を基準として保存します。未登録なら「?」内の「試験3人を登録」で追加できます。初回は●を出しません。以降はアプリを開く・戻ると自動照合し、より新しい本人投稿IDを受け取った人を●で表示します。画面上のボタン操作は不要です。手動の「今すぐ確認」は「?」内にあります。

✔は人間がXの投稿を確認した記録です。いいねの記録ではありません。確認で●を消し、取り消すと直前の未読状態に戻します。RSS取得失敗・対象外・投稿なしは新着未判定として扱い、勝手に「新着なし」と断定しません。

無料RSSは提供元の説明では約24時間ごとに更新され、直近20件です。返信は含まれず、リポストは混在します。高頻度投稿や配信停止は見逃し得ます。X公式APIではなく外部RSSです。利用条件や配信仕様が変わる可能性があります。PWAを閉じている間の常時巡回や端末通知はありません。

この試験版は旧 `v051-ui-test/` と別のPWA ID、パス、IndexedDB、サービスワーカーキャッシュを使用します。初回は旧UI試験版の保存データを読み取り専用で複製し、以降は同期しません。旧版の保存データは変更しません。JSONの保存・復元にはRSS確認記録も含まれます。初回利用前にも旧版でJSONを保存してください。

Android実機での動作は未検証です。詳しい結果はRESULT.md、確認手順はAndroid.mdをご覧ください。
