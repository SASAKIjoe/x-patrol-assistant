## 使い方

タブレット幅（600px以上）の候補一覧で、行の左の `≡` をつかんで上下へ動かします。離すと並び順が保存され、自動で「手動順」へ切り替わります。行の通常の場所はスクロール・タップ開閉に使えます。小さいスマートフォン幅にはつまみを出しません。

絞り込み中は表示されている人だけを、その人たちが占める場所の中で入れ替えます。非表示の人の位置と順番は維持します。✔を付けても手動順は変わりません。巡回一覧にも保存した順番を反映します。

`≡` の絞り込みパネルで「手動順」と他のソートを切り替えられます。手動以外の表示からドラッグすると、表示中の順番をもとに手動順を保存します。キーボードでは行のつまみにフォーカスしてAlt＋↑／↓。Escapeや操作中断では保存しません。

## データ

順番は既存version 5のpeople配列の順として保存します。個人データ・✔・確認日時・履歴・投稿・ジャンルを作り直しません。最新の保存データにIDで並べ替えを適用するため、別画面からの追加や編集を古いスナップショットで上書きしません。操作中に候補が削除された場合は保存を中止します。

JSONバックアップにも配列順を含みます。別端末で復元した際は、並び順で「手動順」を選ぶと保存順を表示できます。通常のバックアップを続けてください。
