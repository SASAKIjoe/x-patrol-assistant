# Android実機で見ること

1. 先に「保存」でJSONを保存し、RSS試験版の画面を全部閉じてから公開URLを開く。
2. 既存の候補数と✔が残り、候補一覧に更新ボタンがないことを確認する。新しい候補を1人登録し、初回は−のままか確認する。
3. 登録が多ければ一覧上部の「↻ 済/全」の進み具合を見る。途中で閉じて開き直し、続きが進むか確認する。
4. 1～2日後に開き、本人の新しい投稿がRSSに届いた人だけ●になるか見る。Xから戻って✔と取り消しも確認する。
